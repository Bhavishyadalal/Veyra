# Immersive worlds · artwork provenance

The Aurora Drift backdrop is original artwork generated for Veyra using the
session's OpenAI image-generation tool on 26 October 2026. The runtime image is:

`sharedUi/src/commonMain/composeResources/drawable/immersive_aurora.webp`

It is exported at the original 1024×1536 dimensions, without added labels or UI,
as a 167,778-byte WebP. The PNG original remains in the generation workspace;
the complete native build input is the bundled WebP. No network fetch is needed
for this backdrop and no source photograph, external logo or character is used.

Generation direction: an original cinematic midnight alpine lake under sculptural
mint/teal/violet northern lights, distant mountains in the bottom sixth, a spacious
dark center for the playing song's sleeve, sparse stars, no text, UI, logo or people.

Vinyl Lounge, Neon Tunnel, Paper Reverie, Orbital Atlas and Prism Bloom use native
Canvas paths, gradients and shapes. Their album art comes from the playing song.
Paper uses the platform serif family; no additional font binary is downloaded.

Production-UI screenshots and the six-mode contact sheet are under
`themes/previews/immersive-worlds/`. They use a clearly controlled test fixture
and show the real Compose renderer, not AI-generated app mockups.
