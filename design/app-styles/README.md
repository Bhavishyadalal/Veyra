# Veyra app styles

Preview-only visual systems alongside Original: Music Editorial, Listening Room and After Dark.

- Listening Room background: generated with OpenAI image generation on 21 October 2026 for Veyra. Optimized WebP lives at `app/src/main/assets/app-styles/listening-room.webp`. No bundled stock portraits.
- Cormorant Garamond variable font: Google Fonts `ofl/cormorantgaramond/CormorantGaramond[wght].ttf`, downloaded 21 October 2026. Copyright and SIL Open Font License in `CormorantGaramond-OFL.txt`; bundled app resources and license assets are generated from these sources.
- Body font: existing licensed Manrope sources. After Dark display font: existing licensed Barlow Condensed sources. Their existing OFL assets remain in the APK asset inputs.
- Editorial paper and After Dark ambient/record artwork are static native vector drawing. There are no perpetual decorative animation loops.

The approved AI three-screen concept is a visual reference, not a screenshot or measured Android layout. Native implementations adapt to insets, RTL, large text, real content and small screens. Original retains downloadable themes; custom styles never replace/delete its saved theme or font selection. This does not add launcher icons or change the app version.
