# Asset-pack display fonts

Unmodified Google Fonts sources: Bangers, Lilita One, Audiowide and Bungee from
`https://github.com/google/fonts/tree/main/ofl/`; Rock Salt from
`https://github.com/google/fonts/tree/main/apache/rocksalt` (Apache 2.0).
Each binary has its original license notice beside it and inside its pack.
Manrope body type is the existing licensed theme source. Display faces are used
only for headings; song titles, body text and small labels remain Manrope.
