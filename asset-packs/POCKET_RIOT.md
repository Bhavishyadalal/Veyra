# Pocket Riot · ten cute, bold overlays

![Actual shipped control skins](previews/pocket-riot/collection.webp)

Kitty Mayhem · Mochi Moshpit · Peach Bruiser · Bunny Voltage · Cherry Bombshell · Teddy Tantrum · Bubble Fang · Sugar Goblin · Cosmic Pudding · Sticker Syndicate.

Every pack has 119 runtime roles, separate pressed play/pause/skip controls, licensed heading/body fonts, original editable vectors, native material/progress/page presets and an offline specimen. The theme keeps its wallpaper and palette; existing category switches control which details are overridden. No executable code or remote layouts are installed.

The 27 newly generated glass waveform editions cover all missing Chaos Studio theme/asset mappings and these ten overlays. All 72 themes and 32 overlays now have explicit bundled launcher choices; unknown IDs cannot select arbitrary components. Aliases require build 46+; the packs themselves use the existing code-33 data engine. Existing pack ZIPs are immutable.

Build new overlays with `python3 asset-packs/build_pocket_riot.py`; restore catalog routing with `python3 scripts/route_catalogs.py`. Compile checked-in reviewed masters with `python3 scripts/build_pocket_icons.py`. Generation provenance and master hashes are in `design/launcher/pocket-riot/`; original PNGs remain in the authoring workspace. Standard launcher export resizing/encoding preserves their design. No fonts are modified.
