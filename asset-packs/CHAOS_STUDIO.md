# Chaos Studio · seven independent asset overlays

[Actual runtime specimens](../themes/previews/chaos-studio/index.html)

Gummy Signal · Razor Petal · Disco Chrome · Paper Revolt · Velvet Sigil · Patch Party · Pixel Fizz.

Each pack contains 119 roles, separate pressed transports, licensed heading/body fonts, native material/progress/page-motion presets and an offline preview. Themes keep their palette and wallpaper. Existing category switches determine which controls, icons, type or motion an overlay replaces; the new app Motion studio can independently override page motion. No launcher alias or replacement brand is added.

Editable originals: `vectors/<pack>/`. Installed specimens: `previews/<pack>/`. Immutable distribution: `packs/<pack>-v1.zip` and its SHA-256. Build with `python3 asset-packs/build_chaos_studio.py`, then restore beta catalog routing with `python3 scripts/route_catalogs.py`. Requires the existing code-33 asset engine; previous packs are unchanged.
