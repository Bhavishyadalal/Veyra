# Veyra 0.1.6 · Your space, ready sooner

**Stable source · version code 22 · Made by Bhavishya Dalal**

Promoted from the completed 0.1.6-beta1 preview. The Android package identity and
signing configuration remain unchanged. Code 22 upgrades preview code 21 when
signed with the same release key. No APK or GitHub release is published here.

## Home and artwork

- Restore saved Home content immediately while refreshing in the background.
- Customize Home section order and visibility; access Downloads and Local Music offline.
- Bounded artwork prefetch, persistent image caching and loading fallbacks.

## Make it yours

- Accent palettes, artwork corners, list spacing and Full/Subtle/Off motion.
- Stronger text, higher-contrast player controls and a priority player-menu action.
- Scoped reset confirmations preserve accounts, music and unrelated preferences.

## Interface and navigation

- Refined Settings, player menus, queue/lyrics drawers and compact-screen layouts.
- Single Settings Back icon, consistent category/search navigation and saved scroll state.
- Prevent hidden Settings/detail handlers from consuming visible-screen Back gestures.
- Immediate scroll-bounce return, interruptible springs and calmer shared transitions.
- Welcome name-entry artwork and preserved onboarding input state.

## Service and compatibility

Listen Together continues to use **https://veyra-listen-together.onrender.com**.
Guest participation and intentional custom servers remain supported. External
12-minute cron support and mirrored backend source remain unchanged.

## Verification and limits

Promotion changes version metadata and documentation, not the tested preview UI.
Focused preview Kotlin checks passed; their scope and device follow-up are in
[Settings verification](verification/SETTINGS-BACK-0.1.6-beta1.md) and
[motion verification](verification/SCROLL-MOTION-0.1.6-beta1.md).
The stable metadata is checked separately. Source archives are verified for
integrity, source hashes and the backend mirror. No new APK was assembled or
installed during promotion; the owner will publish the signed APK separately.

## Next preview

0.1.7-beta1 is planned for downloadable theme packs (fonts, icons, artwork,
colors and supported player styling). It is not included in this stable version.
