# Veyra 0.1.8

**Stable · version code 28 · 21 October 2026**

The completed 0.1.8 beta is now the stable Android source on `main` and `stable/0.1.8`.

## Make it yours

- Three optional app styles alongside Original: **Music Editorial**, **Listening Room** and **After Dark**, with coordinated screens and controls.
- Stronger theme artwork throughout Home, Search, Library, artist pages and deeper components; refined navigation and connected player controls.
- **46 downloadable themes** and **74 launcher choices**, an All icon filter and cached Theme Studio previews.
- Independent app and lyrics fonts, imported TTF/OTF support, lyric sizing and centering. Custom app styles retain their own typography.

## Your listening experience

- Immersive player with song, theme, blended or minimal backgrounds, positioned synced lyrics and accessible controls.
- Five additional widgets: **Sleeve**, **Vinyl**, **Studio Strip**, **Lyrics** and **Listening Studio**, with cached artwork and event-driven updates.
- Home greeting, Speed Dial, shortcut choices and Quick Picks behavior.
- Configurable navigation destinations, ordering, startup screen, labels and supported bar designs.
- Player/mini-player appearances, optional seeking gestures, duration display and output-device visibility.
- Data Saver, preload choices, content-country selection and hash-checked backup previews with portable selected font assets.

## Refinements

- Clearer Player, Mini player, Gestures and Network settings sections, with grouped Home, navigation and font controls.
- Lazy preset lists, cached country names and fewer active settings subscriptions while sheets are closed.
- Lighter transitions, a complete account-panel closing animation and guarded preset dismissal that remains retryable if interrupted.
- Search cancellation and stale-result protections, source-aware lyric updates and theme-install validation fixes carried forward.

## Updating

Version name is **0.1.8**, without the beta suffix; version code rises from beta **27** to **28**. Rebuild and install the production APK with the same signing key to update an existing installation. The source ZIP is an Android Studio project, not an installable APK. Published theme-pack bytes and existing stored selections are preserved.
