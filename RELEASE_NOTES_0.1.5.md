# Veyra 0.1.5

Your music. Your space.

## Refined throughout

- **Home:** clearer headings, polished artwork cards and fallbacks, improved banner controls, safer layout switches and an empty-feed refresh action.
- **Player:** bold transport controls, pressed and loading feedback, smoother deck transitions, safer seeking and improved large-text/RTL behavior.
- **Settings:** clearer structure, refined rows and sheets, and improved account/integration presentation while preserving existing actions.
- **Accessibility:** reduced-motion handling and more comfortable control targets across the promoted components.

## Listen Together, powered by Veyra

Room synchronization, invites and app presence use Veyra's independently hosted backend. Guest access and intentional custom servers remain supported. Old managed server settings migrate automatically; rooms from the previous service require a fresh invite.

External cron and a best-effort 12-minute GitHub keep-alive support the shared backend. Free-hosting sleep, restarts and temporary unavailability can still occur; restarted servers lose active rooms.

## Updating

Stable **0.1.5**, version code **20**. Install the release signed with the same key as your existing Veyra installation to update in place. Existing package identity, settings, library and downloads are retained by this source change. Both beta code 18 and earlier stable code 19 can upgrade to code 20.
