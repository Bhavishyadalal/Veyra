# Stable 0.2.0 · build 53 · listening usability

Version name stays **0.2.0**; Android version code **53**.

## Home recovery

The existing cache-preserving Home loader can retain recommendations when a network refresh fails. Previously the status header explained the failure without offering a direct action, leaving recovery dependent on pulling to refresh (which users can disable). The header now offers Retry using the same artwork-aware refresh callback. It is disabled while updating and omitted offline, where existing Downloads/Local Music actions remain available. This does not clear the feed or restart playback.

## Search that reflects the current query

- Editing invalidates old requests as before and now immediately clears the previous query's visible results/completions. No new full search request is generated by typing; existing debounced suggestion pipelines remain.
- A draft without completions gets a ready-to-search card and Search action. Suggestions include an explicit exact-query action.
- Live media suggestions no longer require the separate text-completion request to succeed. Text completions are deduplicated case-insensitively at publication; displayed completion/media keys are deduplicated defensively.
- Selecting a history/suggestion entry, playing a result or opening a browse result clears focus and hides the keyboard. A user drag dismisses typing; automatic/programmatic scroll resets do not. Clearing the field still focuses it for editing; a blank IME submission does not submit or dismiss it.
- Top-result actions use wrapping layout rather than squeezing an inflexible row. The heading is now a resource string.

## Shared visual feedback

Empty/error messages use centered, rounded cards, a subtle palette-derived border, readable on-surface text and an optional action. Width is bounded on wide windows, messages wrap, and there is no added animation or image/network work. Theme artwork remains in the screen background; theme/asset icon routing remains in use for controls. Existing queue jump-to-current, upcoming summaries, clear confirmation and undo were reviewed and retained.
