# Chaos Studio · ten full themes

[Actual wallpapers, installed fonts, buttons and every-role sheets](previews/chaos-studio/index.html)

Soda Sabotage · Velvet Vandal · Acid Daydream · Peach Panic · Ink and Ivory · Holo Havoc · Denim Disorder · Cherry Voltage · Mint Mutiny · Lunar Lollipop.

Each pack contains original AI wallpaper, 123 semantic asset roles, independently rendered pressed play/pause/skip buttons, colored display headings, readable Manrope body text and original font licenses. Seven authored frame families include inflated gel, petal seals, faceted chrome, torn print, gothic arches, stitched patches and stepped arcade panels. Existing native material/seek presets keep rendering bounded; no executable code or remote layout is installed.

Runtime original WebP artwork is in each theme's artwork directory and ZIP. `chaos-art-sources.json` records generation provenance; original high-resolution PNGs remain in the authoring workspace. Reviewed glass brand editions are reused; this collection does not add launcher aliases. Build with `python3 themes/build_chaos_studio.py`, then `python3 scripts/route_catalogs.py`; existing published pack bytes must never be overwritten. Seven independent Chaos Studio overlays can be applied over these or any other supported theme.
