# Worlds — twenty new Veyra themes

**All fifteen proposed themes, plus five image-inspired themes.** Latest preview **0.1.7-beta1 / code 25** now has **41 themes and 69 launcher choices**. All prior packs, theme choices and Glass Atelier icons remain available.

**Rebuild/install the latest preview source first.** This collection expands the catalog beyond the older 24-theme parser limit. Earlier builds may fall back to their bundled older collection; refreshing alone cannot update the parser or add launcher aliases. The app remains on the preview track; stable 0.1.6 is unchanged and does not support these packs.

Then open **Settings → Appearance → Theme studio → Refresh**, choose a theme, Download → Apply. Matching launcher selection is explicit and optional. Theme ZIPs are data packs, not APKs.

## Coherent native theming

Every pack includes a nine-color readable palette, licensed heading/body fonts, scene mapping for banner/player/preview, matching Home brand icon, thirteen functional glyphs, control corners and timeline styling. Navigation home/search motifs are specific to each world; compass/books and transport silhouettes remain familiar. The existing themed bottom-bar material follows the palette and geometry with static route, light-line or bubble details.

The collection list and launcher grid are already lazy. The catalog cap increases from 24 to **64**, retaining the **65,536-byte response limit**, strict host/path checks, duplicate-ID checks, hashes and bounded pack installation. This collection fits within that byte limit. No unbounded catalog, animated wallpaper or new visual dependency is introduced.

Original Veyra restores saved appearance. Existing Google accounts, guest-friendly rooms, real music artwork, queue and playback behavior remain intact. Launcher switching is independent and optional; removal does not overwrite a manually chosen icon. Reduced motion continues through the existing engine.

## Provenance and rebuilding

Twenty original scenes and twenty icon edits were commissioned for this collection; two scenes were refined after review (42 AI generation/edit calls total). The five attached references inform Quiet Horizons, with error-message text omitted from artwork. Blue Hour Sanctuary deliberately uses a wisteria garden and stream rather than repeating Azure Bloom's single-tree composition. The other fifteen themes implement the previously proposed directions. Icons use the official `design/launcher/wave_glass.png` as their identity reference. Original reference attachments are not redistributed.

Reviewed 1024 px icon masters and compact scenes are checked in; functional glyph SVGs are under `source-icons/<theme>/`. Original licensed font files/notices remain included. `worlds-designs.json` records each art direction. Rebuild only this collection offline with `python3 themes/build_worlds_collection.py`. The shared compiler supports per-collection WebP quality while retaining earlier packs' defaults and immutable bytes. All v1 hashes are fixed after publication.

Source ZIPs retain theme assets/fonts/packs and the renderer, omit duplicated generated studies under `themes/previews/`, and use stronger ZIP compression. Existing published assets are not deleted or recompressed in the repository. Native studies remain available through this document and the gallery.

Linked interface studies use actual shared Compose components with illustrative surroundings. They are **not Android device screenshots**. Sample covers are demonstration art; the app preserves real music artwork. [Verification and hardware limits](../verification/WORLDS-COLLECTION-0.1.7-beta1.md).
